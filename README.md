# 百宝箱

一个面向日常开发和网页调试场景的轻量浏览器工具箱，基于 WXT、Vue 3 和 TypeScript 构建。

## 功能

### 媒体拾取

- 从插件首页一键进入拾取模式。
- 根据鼠标坐标获取页面中的元素命中栈，可以识别被同级元素覆盖的媒体。
- 支持图片、视频、音频、SVG 图片、CSS 背景图和遮罩图地址。
- 点击页面锁定候选，使用 `Tab`、方向键或浮层按钮切换媒体地址。
- 支持复制当前媒体地址、重新选择以及按 `Esc` 退出。

暂不处理跨域 iframe、关闭的 Shadow DOM、Canvas 和 WebGL 等特殊情况。

### Cookie 管理

- 查看当前页面的 Cookie。
- 使用完整 Cookie 文本添加 Cookie。
- 复制或删除指定 Cookie。

### Cookie 同步

从插件首页打开「Cookie 同步」，在独立页面管理规则。来源、目标和 Cookie 名称均可配置。

- 手动同步：点击规则上的「立即同步」。
- 更新时同步：来源 Cookie 新增或更新后，自动单向同步；不跟随删除。
- 访问前同步：每次打开或刷新目标网站时，经过同步页后继续访问。
- 登录回跳同步：记录同一标签页从目标网站进入指定登录页的流程，在返回目标时同步。
- 支持启停、执行结果和配置导入导出。导出文件不包含 Cookie 值，导入的规则默认停用。

**验证 test → localhost 登录流程：**

1. 构建并在 Chrome 扩展管理页重新加载插件，关闭旧的 Cookie 同步管理页面后重新打开。
2. 新建规则，来源填 test 的业务地址，目标填本地地址（包括端口）。
3. 读取并勾选登录 Cookie，或手动填写 Cookie 名称。执行时会读取最新值。
4. 「访问目标网站前」选择「仅登录回跳时同步」，填写实际登录页的地址或路径前缀。
5. 保存后，从 localhost 发起登录，完成登录后应自动回到原业务地址。需要同步失败详情时查看规则卡片或中转页。

目标匹配以协议、主机、端口和路径边界为准。例如 `/app` 匹配 `/app` 和 `/app/orders`，不匹配 `/apple`。登录页可以包含 hash 路由；路径、查询参数和 hash 会在回跳时保留。

第一版主要用于 **Chrome、同标签页、GET 整页跳转、未分区 Cookie**。登录弹窗、跨标签页回调、POST 回调、依赖 localStorage 的凭证、Service Worker 自行处理的页面导航需要另行适配。「仅登录回跳」已验证实际显示登录页面的流程；如果来源已有登录态、服务器会瞬间连续 302 回跳，请选择「每次打开或刷新目标网站」，在首次请求前同步现有 Cookie。

Cookie 会写成目标主机专属 Cookie，保留 HttpOnly、原路径和有效期。可以选择统一根路径，或为 HTTP 目标关闭 Secure 并将 SameSite=None 改为 Lax；安全前缀 Cookie 需要 HTTPS。来源缺少任一选定 Cookie 时不会部分写入。不同 localhost 端口共享 Cookie，同名写入冲突会在启用规则时提示。

### 二维码

- 检测当前页面图片中的二维码。
- 鼠标悬停图片时识别二维码内容。
- 复制识别结果或下载二维码图片。

## 本地开发

```bash
pnpm install
pnpm dev
```

类型检查和生产构建：

```bash
pnpm compile
pnpm build
```

构建产物位于 `.output/chrome-mv3`，可以在 Chrome 扩展程序页面中通过“加载已解压的扩展程序”进行安装。

扩展重新构建或重新加载后，已经打开的网页需要刷新一次，以重新注入最新的内容脚本。

## 图标

扩展图标位于 `public/icon`，使用以下命名：

```text
icon-16.png
icon-32.png
icon-48.png
icon-96.png
icon-128.png
```

## 权限

- `cookies`：读取和修改当前页面及同步规则中指定站点的 Cookie。
- `tabs`：获取当前活动页面，并向页面发送工具指令。
- `storage`：保存同步规则、执行结果和临时登录流程，不持久保存同步的 Cookie 值。
- `webNavigation` / `webRequest`：识别页面导航与登录重定向链；只观察主页面请求，不读取请求体。
- `declarativeNetRequestWithHostAccess`：在目标主页面加载前进入同步页，并临时放行本次返回导航。
- `<all_urls>`：在网页中运行二维码识别、消息提示和媒体拾取功能。
